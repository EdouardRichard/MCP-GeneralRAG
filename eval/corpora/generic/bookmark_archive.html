Team Bookmark Archive: Retrieval and Infrastructure

Shared bookmarks collected by the retrieval platform team. Newest entries first within each section. Last pruned: 2026-08-30.

Vector Databases

Qdrant filtering guide — the definitive reference on payload filters and hybrid (dense + sparse) queries. Our production deployment follows this guide for the named-vector layout.

PostgreSQL pgvector versus dedicated vector stores — a fair benchmark write-up; the conclusion matches our experience: pgvector is fine below about 5M vectors, dedicated stores win at scale with filtered search.

Embeddings and Reranking

Sentence-Transformers documentation on multilingual models — background on how bge-m3 handles cross-lingual retrieval and the s2-tuning recipe.

Cohere rerank API cookbook — practical patterns for two-stage retrieval (retrieve-then-rerank) including latency budgets per stage.

Evaluation

BEIR benchmark repository — heterogeneous retrieval tasks; useful sanity check before trusting any single-domain eval number.

Ragas framework docs — reference-free RAG evaluation metrics (faithfulness, answer relevance). We borrowed the idea of grounding checks from it.

Engineering Blogs

Cloudflare engineering blog on cache residency — not retrieval, but the tiered-cache idea inspired our evidence freshness badge design.
