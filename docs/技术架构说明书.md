## 1. 系统定位与边界（重建骨架）

系统在 1.0/2.0 中是**面向单用户、多知识域工作场景的检索增强服务**：摄入语料、构建索引、经 MCP 向外部 Agent（ChatGPT App / Claude Code / DeepSeek Harness）提供带来源定位的证据。3.0 将其演进为**外置型记忆系统**：在检索服务之上叠加**记忆回路**——写入 → 巩固 → 召回 → 反馈——使外部 Agent 从"每次会话失忆重来、每次现查语料"变为"带着记忆工作"。

**3.0 七项可度量目标**（逐字取自实施蓝图 §1，**是目标而非实测结论**）：① MCP 记忆工具可用且旧三工具零破坏；② 硬记忆锚定率 100% + 软/distilled provenance 完备率 100%；③ 跨域记忆串库 = 0；④ 巩固受益 ≥3%；⑤ 跨会话续接达标；⑥ 记忆投毒 E2E 全过；⑦ 既有评测全集无回归。目标 ④ 在 013 已确立为**未达成且不可计算**（`incomplete`、`default_enable_eligible=false`、开关默认关闭、`relative_gains` 0.0/0.0），本说明书如实继承、不改写。

**边界（不变）**：系统**不生成最终产物、不做产出质量门禁**；宿主 Agent 的短期上下文由其自管（`auto-compact` / context editing），系统只提供**续接锚点**（会话登记 + 工作集 recall）。

## 3. 核心设计原则（重建骨架）

1. **`knowledge_scope` 是唯一隔离单元**，记忆条目与知识条目同受三道防线约束；跨域串库为安全类硬指标，零容忍。
2. **日志为真、视图为用**：任何状态变化的唯一写入点是 append-only 事件日志；一切派生投影只读且可重建。
3. **确定性裁决优先**：LLM 只提议，不生效；生效路径由确定性代码裁决（巩固裁决器、分级信任校验、注入检测）。
4. **纠正即失效而非删除**：`supersede` 链 + 双时间轴，历史事件永不改写。
5. **评测驱动**：新增能力必须经固定评测集与对照闸门才有资格进入默认路径；未过闸即如实记未达成并给触发条件。
6. **零分母不记 0**：分母为零的指标记 `not_measurable`，不记 0、不记达标；未执行不记通过。
7. **fail-loud / fail-closed**：安全类校验失败闭合（拒绝写入），不做静默放宽；降级必须显式报告。

## 5. 记忆回路（3.0 新增章）

本章是本次唯一的**新增章**。它描述已交付的实现（012/013/014）与 015 正在建立的评测治理面，不描述未实现的能力。

### 5.1 权威层：G2+ 不可变事件日志

**唯一写入点**：`memory_events`（append-only，永不 UPDATE / DELETE 语义）。所有"记忆当前态"都是它的派生物；任何绕过日志直接改投影的行为都属破坏轨迹正确性（代码评审 + 测试双重防守）。

**事件类型**（7 种）：`assert`（新增；hard 须锚证据、soft 须完整推断元数据）、`revise`（纠正；追加新事件、以 `valid_to`/`superseded_by` 表达失效）、`retract`（墓碑；退出默认消费而**不物理删除**）、`consolidate`（巩固产出，须经确定性裁决）、`access`（取用留痕，高频段，TTL 90 天）、`grant`（权威/绑定授予）、`rollback`（回滚到时间点或事件点）。

**管理面专属事件**：实现层强制 `grant` 与 `rollback` 的 `actor` 必须是 `management`（`services/memory_event_store.py` 对 `event_type in {"grant","rollback"}` 校验 actor），MCP 面无法伪造该写入者。

**双时间轴**：`valid_from` / `valid_to`（事实时间）+ `observed_at` / `invalidated_at`（系统时间）；默认视图只回 active 且当前有效的条目。

**六轴状态元数据**：`GOVERNANCE_AXES = (authority, scope_meta, mutability, provenance_meta, recoverability, actionability)`——事件的每一行都携带这六轴，供治理与审计逐轴断言。

**日志分段**：权威段（assert / revise / retract / consolidate / grant / rollback）长存，周期快照后可截断至审计窗口；高频段（access）TTL 90 天，其效果已物化进显著性投影。

### 5.2 六个派生投影视图

`services/memory_projection_store.py:23` 的 `VIEW_KEYS` 是投影集合的唯一真相源，**恰好六类**，`versions()` 强制六类齐全（缺一即失败）：

| # | 投影 | 载体 | 服务 | 重建方式 |
|---|---|---|---|---|
| ① | **关系**（relation） | PG `memory_entries` 等表 | 结构化查询、约束校验 | 日志回放 |
| ② | **向量**（dense） | Qdrant `memories_dense_{index_version}` | 语义召回 | 重嵌入 |
| ③ | **链接**（links） | PG 类型化边表（013） | 关联导航 + 依赖传播 | 巩固重跑 |
| ④ | **摘要**（summary） | `DIGEST.md` / `INDEX.md` | 低唤醒成本导航 | 巩固重跑 |
| ⑤ | **文件**（file） | `memory_projection/{scope_slug}/{kind}/*.md` | 宿主直读、人工审计 | 全量导出 |
| ⑥ | **显著性**（salience） | `memory_salience` 表 | 留存/调度 + 排序（带衰减） | `access` 回放 |

**只读与可重建的双重保证**：
- **逐投影指纹**：`projection_fingerprint(state[key])` 为每个视图计算指纹，并随 `MemoryProjectionMeta` 落盘（含 `state_fingerprint` 与 `fingerprints`）。
- **回放一致性校验**：`ProjectionRebuilder.inspect()` 返回每个视图的 `{count, fingerprint, matches_replay}`；`set(report) == set(VIEW_KEYS)` 且全部 `matches_replay` 为真才通过。
- **事件链闭合**：`runtime/projection_rebuild.py` 在回放时要求回放 id 序列与权威日志**逐项相等**（不等即 `MEMORY_WRITE_UNAVAILABLE: incomplete immutable checkpoint log`）。**注意**：判据是"序列逐项相等"，**不是**"id 数值连续"。

**单一 status 真相**：`status` 不下推 Qdrant 过滤（payload 陈旧会造成假阴性）；`knowledge_scope_id` 强制下推，`kind` / `session_id` 可下推（不可变字段）。

### 5.3 五条强制不变量（与强制点、机器判据）

| 不变量 | 语义 | 实现层强制点 | 机器判据（015 AOEP 口径） |
|---|---|---|---|
| **回滚可溯** `traceable_rollback` | 回滚必须有事件、可复算、可再次回滚 | `rollback` 事件 + 前后快照指纹；仅管理面；`event_point` 与 `time_point` 二选一 | 回滚事件存在 + 事件链闭合（回放序列与权威日志逐项相等）+ 水位可读 + 全状态指纹一致 + 逐投影指纹相等 + 影响面计数一致 + 可再次回滚；**仅有审计记录而无事件链证据必须判失败** |
| **删除传播** `deletion_propagation` | 墓碑后条目在**每个**消费面都不可见 | `retract` 经 reducer 传播到关系/向量/链接/摘要/文件五投影 | 对五投影**各自独立断言**"该条可消费命中数 = 0"，且**各自分母非零**（传播前该条在每投影可被观测）；任一投影分母为零 → 该投影记 `not_measurable`，不计达标也不跳过；显著性是字段投影，**不参与**本断言 |
| **权威单调** `authority_monotonicity` | 被拒的越权操作不得改变任何状态 | 写入校验：actor 权威 ⊆ 声明权威；`grant` 仅管理面；绑定表不可经 MCP 改写 | 越权/非法命令全部被拒（403 或结构化错误）且**权威日志 id 序列逐项相等**、绑定表行集不变、权威等级字段不变、每次拒绝留审计 |
| **范围不扩张** `scope_non_expansion` | 解析失败/歧义即拒；记忆单域；查询多域显式 | `validate_memory` 对缺失或空 `scope_ref` 抛 `MISSING_KNOWLEDGE_SCOPE`；歧义引用给候选而**不回落**最近域/全库 | 缺失/空与歧义**各自构造用例、各自非零样本量、分别记分**；"回落最近域/全库"成功次数 = 0；跨域串库 = 0 |
| **来源保全** `provenance_preservation` | 状态转移后来源链与内容指纹仍可复算 | 事件不可变；投影重建不丢来源链；`retract` 后权威日志保留墓碑事件与来源链 | 状态转移（含 `retire`/`purge`/`rollback`）后 provenance 元数据、来源链与 `content_hash` 保留且**重算值与记录值逐一相等** |

**分级信任（不变量落地前置）**：`hard` 记忆必须携带 `evidence_refs` 且 `confidence is None`；`soft` / `distilled` 必须携带五元推断元数据 `{source, confidence, model_version, time, supporting_evidence}`，缺一即 `MEMORY_INFERENCE_META_INCOMPLETE`（`services/memory_validators.py`）。写入前统一脱敏 + 注入检测：`risk_level == "high"` 映射为 `status = "quarantined"`（隔离态），低危/无命中为 `active`；`_validate` 会重跑脱敏并要求载荷中的 `status` / `injection_flags` 与之一致，构成"标记与隔离不一致"的一致性闸口。

### 5.4 回滚与管理面边界

**回滚语义**：重放到时间点 `T` 或事件点 `event_id`，重建全部投影，并生成 `rollback` 事件（含回滚依据、影响面、前后指纹）。`event_point` 与 `time_point` **必须且只能给一个**；时间点折算为 `occurred_at <= time_point` 的末条事件 id。

**权限边界（仅管理面）**：回滚是**新增攻击面**，故**仅管理面（人）可达**；MCP 面**不暴露**回滚入口或能力。实现层通过 `actor == "management"` 强制，管理 REST 由 writer 实例 + `require_writer` 依赖承载。

**管理面 REST 面**（`api/memory.py`，前缀 `/api/memories`）：`GET /scopes`、`GET ""`（浏览，`scope_ref` 必填）、`GET /bindings`、`GET|POST /policy`、`POST /retire`、`POST /purge`、`POST /usage`、`POST /rollback`、`POST /bindings`、`POST /promote`、`GET /promotion-candidates`、`GET /promotions/{task_id}`、`POST /consolidation`、`GET /consolidation/runs`、`GET /consolidation/runs/{run_id}`。破坏性操作（`purge` / `retire` / `rollback`）须经**强确认**（逐字输入目标确认值，含显式域引用），首期**仅单条**、无批量入口。

**回滚的外部承诺边界**：回滚不回滚"外部承诺"（3.0 范围外，Q48 预留六轴）。

**管理面与 MCP 面的能力对照**：

| 能力 | 管理面 REST | MCP 六工具 |
|---|---|---|
| 写入记忆 | 经治理动作间接 | `record_memory`（**仅 writer 实例**） |
| 读回记忆 | 浏览/统计 | `recall_memory` / `start_work`（writer + reader） |
| 下线 / 清理 | `retire` / `purge`（强确认） | **不可达** |
| 回滚 | `rollback`（强确认） | **不可达** |
| 投影重建 | 管理面触发 + 校验报告 | **不可达** |
| 晋升 | `promote`（人工） | **不可达**（且**无自动晋升入口**） |
| 策略编辑 | `GET|POST /policy` | **不可达** |

### 6.2 记忆事件与命令契约

- **事件类型枚举**（7 值）：`assert` / `revise` / `retract` / `consolidate` / `access` / `grant` / `rollback`（只增不删）。
