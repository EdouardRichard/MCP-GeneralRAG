## §1.3 目标逐项核销

### 目标 1：外部 Agent 以 domain_scope 对任意知识域执行检索增强，旧 project_scope 客户端零破坏

**判定：✅ 达成**

- 007（knowledge-domain-generalization）交付双轴知识域模型 + domain_scope 三形态寻址（数字 ID / slug / type:name）+ 统一引用解析器 + list_knowledge_domains 发现工具；project_scope 保留为兼容形式，旧码行为不变。
- 011（本 Feature）在混合域环境实证：eval/multi_domain_acceptance_report.json —— 发现 → 三形态寻址 → search_knowledge → get_evidence 完整闭环，≥4 个语义轴（personal/generic/legal/se-project）全覆盖；仅 project_scope 旧码不变、双参数混用并集去重、无引用请求被拒（FR-022）。
- 证据工件：specs/007-knowledge-domain-generalization/、eval/multi_domain_acceptance_report.json、backend/tests/integration/test_011_multidomain_acceptance.py。

### 目标 2：新增一种通用文档格式的边际成本 ≤ 2 个文件（注册表条目 + 可选小适配器）

**判定：✅ 达成**

- 008（universal-ingestion-channel）交付 FormatHandler 注册表（格式检测/解析分发/二进制声明/图提取分发的单一事实源）——新增格式仅需在注册表声明条目（+ 可选转换适配器），不再触及 4 处 if/elif + 3 个 DB CHECK + 迁移。
- 证据工件：specs/008-universal-ingestion-channel/（FR-001/FR-002 注册表契约）、backend/src/rag_mcp/parsers/registry.py、backend/tests/unit/test_parsers/test_registry.py。

### 目标 3：首批通用格式（HTML/TXT/CSV/JSON/YAML/XML/XLSX/PPTX/EML）全部可上传、可切片、可检索、证据可定位

**判定：✅ 达成**

- 008 交付 markitdown 转换层，九格式接入（含 100% 可定位定位前缀契约 sheet:/path:/msg:/# 标题路径）。
- 011 个人域语料覆盖其中 HTML/TXT/CSV 三格式（另加 Markdown），四格式全部经真实链路入库/切片/检索/定位（VS-02 断言：csv=sheet:、html/markdown=标题路径、txt=段落）。
- 证据工件：specs/008-universal-ingestion-channel/、eval/generic_domain_baseline_report.json（source_locatability_rate=1.0）、backend/tests/integration/test_011_corpus_ingest.py。

### 目标 4：两个验证域各建 ≥10 条固定评测集并产出域基线报告；1.0 全部既有评测集无回归

**判定：✅ 达成**

- 个人/团队域：eval/generic_domain_eval_dataset.json（13 条，markdown/txt/html/csv 每格式 ≥2 + ≥2 中文，人工审核入库）+ eval/generic_domain_baseline_report.json（dense/hybrid 双路径，经契约 schema 校验）。
- 法律合规域：eval/legal_domain_eval_dataset.json（11 条：条文结构 ≥4 + 交叉引用受益 ≥6）+ eval/legal_domain_baseline_report.json（含 cross_reference_benefit 块）。
- 1.0 既有评测集无回归：eval/011_regression_summary.json —— 001–006 六组口径重跑，002–006 非延迟指标与历史报告逐项一致（delta 0），001 组 recall 一致、MRR/nDCG 为 008 语料重入库的既有改善（单侧非回归门禁通过）。
- 证据工件：上述四份评测集/报告 + eval/011_regression_summary.json + eval/011_*_regression_report.json。

### 目标 5：硬性验收指标在混合域验收集上全部成立（跨域串库=0 / Schema 100% / 定位 100%）

**判定：✅ 达成**

- eval/multi_domain_acceptance_report.json：跨域串库事件 = 0（单域引用不返回他域证据，多域引用证据归属正确）、MCP Schema 合法率 = 1.0、来源可定位率 = 1.0（含 Word 标题路径与 PDF page:N §数字编号前缀证据）。
- 证据工件：eval/multi_domain_acceptance_report.json、backend/tests/integration/test_011_multidomain_acceptance.py。
