# 1.0 → 2.0 Iteration Roadmap

**Last Updated**: 2026-09-07 | **Status**: 2.0 Finalized（001–011 全部交付）

## Delivered Features

### 001 — Minimum RAG MCP Loop ✅
**Delivered**: 2026-08-27

- Dense retrieval (BAAI/bge-m3) with Qdrant
- Markdown + Java ingestion pipeline
- MCP search_knowledge + get_evidence tools
- Web management API (React + FastAPI)
- Baseline evaluation (11 queries, MRR=0.9091, nDCG=0.9329)

### 002 — Hybrid Retrieval Precision ✅
**Delivered**: 2026-08-27

- **BM25 Sparse Encoder** (jieba CJK + regex Latin, hash-based term IDs, frozen vocab)
- **RRF Fusion** (k=60, deterministic tie-breaker, DBSF reserved)
- **Cross-Encoder Rerank** (bge-reranker-v2-m3, CPU, candidate budget=20)
- **Hybrid Retrieval Path** (Dense+Sparse parallel recall → RRF → Rerank → boxing)
- **Partial Degradation** (sparse/rerank failure → partial status with failed_paths)
- **Capability Gating** (lexical_ready, version isolation, rebuild governance)
- **Subpath Timing** (dense/sparse/fusion/rerank/total ms tracked in RetrievalRun)
- **Expanded Eval Dataset** (original 11 + Chinese/lexical queries, 18 total)
- **Comparison Eval** (run_comparison.py: same-session Dense vs Hybrid report)
- **Constitution Compliance**: all 10 principles + 5 hard constraints verified

**Metrics** (research.md §0 targets):
- MRR ≥ 0.95 (baseline 0.9091) — target met via validateToken rank improvement
- nDCG ≥ 0.96 (baseline 0.9329) — target met
- Recall@K ≥ 1.0 — preserved (no regression)
- Cross-project leakage = 0 — enforced by scope filter on both Dense+Sparse
- MCP schema validity = 100% — no contract changes
- Source locatability = 100% — evidence carries source_version + position

### 003 — Structured Asset Expansion ✅
**Delivered**: 2026-09-04

- Word/PDF 原生解析（标题层级切片、page:N 定位、多栏阅读顺序）
- OpenAPI/DDL/Go/Python 结构感知解析器（AST/symbol 路径定位）
- 全格式证据定位前缀契约（heading/page/symbol/path/sheet/msg）
- 格式集评测（37 条混合格式 + 逐格式对照报告）

### 004 — Graph RAG ✅
**Delivered**: 2026-09-05

- 图增强检索路径（graph_enhanced：混合召回 + 图扩展 + 结构权重融合）
- Java 调用图与 DDL 外键硬关系提取（确定性 AST 证据）
- 图扩展 trace 契约与能力门控（graph_ready 声明式发布）
- 图集评测（37 条结构子集对照，三闸口：≥3% 提升 + Recall 非降 + 硬指标）

### 005 — Agentic Retrieval Orchestration ✅
**Delivered**: 2026-09-06

- LangGraph 九步状态机编排（查询规划 → 并行召回 → 融合重排 → 证据分析 → 上下文编排）
- 三 Agent 架构（QueryPlanner / EvidenceAnalyst / ContextOrchestrator，schema 校验判断）
- 注入防御与判断存储（LLM 判断不拥有工作流控制权，宪法 VI）
- agentic 对照评测（组合数据集 63 条，同会话基线对照 + 可重复性）

### 006 — Runtime Hardening ✅
**Delivered**: 2026-09-05

- writer/reader 双实例形态（单写多读、实例注册与 metrics 归因）
- 运行时硬约束实测（泄漏/Schema/定位三件套 + 双写者互斥 + 读写者独立）
- 实例形态冒烟（11 条 × 双形态，单侧非回归判定）
- 超时档案与目标宿主兼容（DeepSeek Harness 必过、ChatGPT/Claude 记录不阻塞）

### 007 — Knowledge Domain Generalization ✅
**Delivered**: 2026-09-05

- 双轴知识域模型（scope_type 结构轴 × domain_key 语义轴）
- DomainProfile 域档案注册表（声明式域差异，内置档案只读保护）
- domain_scope 三形态寻址（数字 ID / slug / type:name）+ 统一引用解析器
- list_knowledge_domains 发现工具 + 能力摘要（仅元数据，无知识内容）

### 008 — Universal Ingestion Channel ✅
**Delivered**: 2026-09-05

- FormatHandler 注册表（格式检测/解析分发/二进制声明/图提取分发单一事实源）
- markitdown 转换层（txt/html/csv/json/yaml/xml/xlsx/pptx/eml 九格式接入）
- 定位前缀体系（sheet:/path:/msg:/# 标题路径，100% 可定位验收）
- 两级 chunk_type 词表与 DB 宽模式 CHECK

### 009 — Domain Neutral Retrieval ✅
**Delivered**: 2026-09-06

- 域中立检索编排（planner 提示词域中立化 + 关系词表槽位填充）
- Project 假设清除（编排/序列化/检索路径的 project 硬编码回退全部消除）
- 005 agentic 等价回归（结构化输出逐条 diff + 1% 相对容差对齐）

### 010 — Graph Relation Registry ✅
**Delivered**: 2026-09-07

- GraphExtractor 插件注册表（format × 域词表发现，唯一写入路径 chokepoint）
- cross_reference 提取器（内部锚点/跨文件相对链接/中英文条文引用，防误报）
- legal 内置域档案 + 受益闸口（最小语料未达标 → R11 声明式空词表补救）
- public/generic 端到端图路径（无 Project 行的域以 domain_scope 走通图增强）

### 011 — Generic Domain Evaluation ✅
**Delivered**: 2026-09-07

- personal 第四内置域档案 + legal 格式族扩展（word/pdf，声明式配置变更）
- 两验证域语料与固定评测集（generic 13 条四格式 + legal 11 条条文/受益，人工审核入库）
- 两份域基线报告（dense/hybrid 双路径非约束性对照锚点，契约 schema 校验）
- 交叉引用受益再验证（富化语料上闸口仍未达标 → legal 维持空词表 R11）
- 多域端到端验收（三形态寻址 + 发现闭环 + 硬指标三件套全过 + 双形态冒烟）
- 001–006 全集回归（六组口径重跑无回归，历史报告零覆盖）
- 前端中英文切换（零依赖资源层 + antd locale + 持久化，后端零改动）
- 文档债清理与 2.0 演进目标逐项核销（docs/2.0-finalization.md）
